Bubble sort works by repeatedly comparing adjacent pairs and swapping them if they're in the wrong order. Each full pass "bubbles" the largest unsorted value to its correct position at the end.

🔄
Passes
One pass = one full sweep from left to right. After each pass, one more element is guaranteed to be in its final sorted position at the right end.
↔️
Adjacent Swaps Only
We only ever compare and swap two elements that are next to each other. This is why it's slow — large movements require many swaps.
📌
Sorted Boundary Grows
After pass 1, the largest element is at index [n-1]. After pass 2, second-largest at [n-2]. The sorted zone grows from the right inward.
⚡
Early Termination
If a full pass makes zero swaps, the array is already sorted. This is the optimization that makes best case O(n) instead of O(n²).

// Pseudocode
FUNCTION bubble_sort(array):
n ← length(array)
FOR i = 0 TO n - 1:
swapped ← false
FOR j = 0 TO n - i - 2:
IF array[j] > array[j+1] THEN
  SWAP array[j] and array[j+1]
  swapped ← true
IF NOT swapped THEN BREAK  // already sorted
END FUNCTION
