Binary Search

Best Case O(1)
Worst Case O(log n)
Average O(log n)
Space O(1)

Binary search is a divide-and-conquer algorithm. By comparing the target with the middle element of a sorted array, it eliminates half of the remaining elements with every step.

📚
Sorted Array Required
Binary search only works on sorted data. The ordering is what lets us safely eliminate half of the array at each step.
✂️
Halve Each Step
Each comparison cuts the search space in half. After k steps, only n / 2ᵏ elements remain.
⚡
O(log n) Time
An array of 1,000,000 elements needs at most ~20 comparisons. Linear search would need up to 1,000,000.
📍
Two Pointers + Mid
Track the active range with low and high. Compute mid = ⌊(low + high) / 2⌋.
array[mid] == target
→
✓ Found! Return mid
array[mid] < target
→
Go right: low = mid + 1
array[mid] > target
→
Go left: high = mid − 1
📖
Looking up a Word in a Dictionary
You don't start at "A" and read every word. You flip to the middle, see the page is past your word alphabetically, then flip to the middle of the first half. Each flip cuts the remaining pages in half.

🎯
Higher / Lower Guessing Game
"I'm thinking of a number from 1 to 100." You guess 50 — they say "higher". You guess 75 — "lower". You guess 62 — "higher". Each clue rules out half of what's left. You'll always win in 7 guesses or fewer.
1
Guess the middle of your range
2

3
"Lower" → search the lower half
4
Always halves your possibilities

// Pseudocode
FUNCTION binary_search(array, target):
low = 0
high = length(array) - 1
WHILE low <= high:
mid = ⌊(low + high) / 2⌋
IF array[mid] == target THEN
RETURN mid   // found!
ELSE IF array[mid] < target THEN
low = mid + 1   // go right
ELSE
high = mid - 1   // go left
RETURN -1   // not found
END FUNCTION
