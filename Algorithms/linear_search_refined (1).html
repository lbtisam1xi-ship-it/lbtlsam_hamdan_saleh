Linear Search

Best Case O(1)
Worst Case O(n)
Average O(n/2)
Space O(1)

The Linear Search algorithm searches through an array and returns the index of the value it searches for.

It is the simplest searching algorithm — easy to understand and implement. It works on any array, sorted or unsorted.

// How it works
①
Scan from the start
Go through the array value by value, starting at index 0.
②
Compare each value
Check whether the current value is equal to the value we are looking for.
③
If found, return the index
Stop searching as soon as a match is found and return the index of that value.
④
If not found, return -1
If the end of the array is reached without finding the value, return -1 to indicate that the value was not found.
array[i] == target
→
✓ Found! Return i
array[i] != target
→
Move to i + 1
i == length(array)
→
✗ Not found, return -1
💡 Note

Searching algorithms leave the array unchanged — unlike sorting algorithms, which modify the array.

If the array is already sorted, it is better to use the much faster Binary Search algorithm — but linear search is the right choice when the array is unsorted.

Manual Run Through

Let's do the searching manually — searching for value 11 in the array [12, 8, 9, 11, 5, 11] — to get a better understanding of how Linear Search works before implementing it.

// What happened?

This algorithm is really straightforward. Every value is checked from the start of the array to see if it is equal to 11 — the value we are trying to find.

When the value is found, the searching stops, and the index where the value is found is returned. If the array is searched through without finding the value, -1 is returned.

SituationUse Linear Search?Reason
Unsorted array✓ YesOnly option — binary search requires a sorted array
Small array✓ YesSimple to implement; overhead of sorting isn't worth it
Searching once✓ YesSorting first would take O(n log n) just for one search
Large sorted array✗ NoUse Binary Search — O(log n) is much faster
Frequent searches on the same data✗ NoSort once, then use Binary Search each time

// Pseudocode
FUNCTION linear_search(array, target):
FOR i = 0 TO length(array) - 1:
IF array[i] == target THEN
   RETURN i   // found!
END IF
END FOR
RETURN -1  // not found
END FUNCTION
