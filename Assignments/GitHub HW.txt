TASK 4: PRACTICE ROLLBACK USING RESET --HARD
============================================================
This task is for practicing rollback after making a mistake.

Using VS Code, create a new file named:

temp.txt

Write the following content in temp.txt:
------------------------------------------------------------
This is a temporary file for reset practice.

Then do the following:
- Add the file
- Commit it by mistake
- View the commit history and copy the previous correct commit hash
- Use git reset --hard <commit-hash> to go back and remove the wrong commit

After rollback, temp.txt should no longer be part of the latest project state.

Commit message for the wrong commit:
------------------------------------------------------------
Add temp file by mistake

Important:
------------------------------------------------------------
This task is for practicing how to completely undo a wrong commit and return to the previous correct state.

TASK 5: CREATE AND RESOLVE A MERGE CONFLICT
============================================================
This task is for practicing conflict resolution.

First, make sure your README.md looks like this:
------------------------------------------------------------
# Git & GitHub Homework

This file is for practicing Git basics.

In a new branch:
------------------------------------------------------------
Create a new branch named:
feature-readme

In this branch, change the second line in README.md to:
This file is for practicing Git and branching.

Commit message in branch:
------------------------------------------------------------
Update README in feature-readme branch

In main or master:
------------------------------------------------------------
Go back to main or master.

Change the same line in README.md to:
This file is for practicing Git and GitHub commands.

Commit message in main/master:
------------------------------------------------------------
Update README in main branch

Merge:
------------------------------------------------------------
Now try to merge feature-readme into main or master.
A conflict should appear.

Resolve the conflict manually, then save the file.

Final commit message after resolving the conflict:
------------------------------------------------------------
Resolve README merge conflict

Then push the final version.
